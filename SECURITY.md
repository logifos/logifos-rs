# Security

logifos-rs is an unpublished bootstrap workspace. No supported release series or
security maintenance schedule is documented. The current JSON boundary checks
request size and nesting, but those checks do not establish the safety of a
complete renderer. Parsing, layout and SVG output are still incomplete.

Reporting gap: this repository does not document a private security contact or
confirm that GitHub private vulnerability reporting is enabled. A private
reporting route still needs to be established by the maintainers. Do not put
sensitive vulnerability details, credentials or exploit material in a public
issue or pull request. A public request to establish a private route should
contain no vulnerability details.
